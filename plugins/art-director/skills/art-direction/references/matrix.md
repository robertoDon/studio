# Direction matrix

Three tables: sector → schools, image → schools, audience → adjustments. Cross the first two, filter with the third. Schools that show up in both of the first two tables are the candidates.

Legend: **M** = good as main · *a* = good as accent.

## 2. Desired image → schools

| Wants to look | Schools that deliver | The detail that carries the image most |
|---|---|---|
| **trustworthy** | Trusted Corporate, Swiss, Refined Minimalism | High contrast, perfect alignment, data with sources, zero surprises |
| **modern** | Refined Minimalism, Dark Tech, Bento, Spatial Glass | Large type with negative tracking, breathing room, short and precise motion |
| **cool** | Dark Tech, Neobrutalism, Y2K, Swiss (dramatic scale) | One unexpected detail, well executed (accent, type, micro-motion) |
| **chic** | Quiet Luxury, Editorial, Japanese | Thin serif, lots of space, little color, excellent photography, nothing shouts |
| **fun** | Pop/Memphis, Clay 3D, Maximalist, Material (expressive version) | Saturated color, rounded shapes, microinteractions that reward |
| **welcoming** | Scandinavian, Organic, Handcrafted | Warm neutrals, soft corners, photos of real people, a close tone of voice |
| **handcrafted** | Handcrafted, Editorial | Paper texture, a serif with personality, hand-drawn illustration, a seal |
| **technical** | Utilitarian, Dark Tech, Swiss | Mono for numbers, density, shortcuts, visible grid |
| **bold** | Neobrutalism, Maximalist, Bauhaus, Sport | Extreme contrast, huge type, flat color, deliberate grid breaks |
| **calm** | Japanese, Organic, Scandinavian, Refined Minimalism | Slow rhythm, lots of empty space, a palette of 2–3 close tones |
| **energetic** | Sport, Pop/Memphis, Y2K | Italics, diagonals, heavy condensed type, big numbers, contrast |
| **affordable-premium** | Refined Minimalism, Bento, Scandinavian | Impeccable finish on simple things (1 px shadow, tabular numbers) |
| **youthful** | Pop/Memphis, Y2K, Neobrutalism, Bento | Expressive type, strong color, cultural references, humor in the copy |
| **natural** | Organic, Scandinavian, Japanese | Earth tones, grain, organic shapes, outdoor photography |
| **smart** | Swiss, Editorial, Utilitarian | Impeccable typographic hierarchy, well-designed data, no ornament |

## 3. Audience → adjustments (apply to any school)

| Audience | Adjustment |
|---|---|
| Children (up to 12) | Touch target ≥ 56 px, icon + word, saturated color, no long text. Clay 3D and Pop/Memphis fit. |
| Gen Z (13–27) | Tolerates boldness; punishes the generic. Expressive type, humor, dark mode, vertical, mobile first. |
| 25–40 professional | Wants speed and finish. Shortcuts, medium density, an "affordable-premium" aesthetic. |
| 40–60 decision-maker | Wants clarity and trust. Type ≥ 16 px, high contrast, social proof, fewer trends. |
| 60+ | Body ≥ 18 px, contrast ≥ 7:1 on main text, targets ≥ 48 px, no hidden gestures, no unlabeled icons. |
| Power user / technical | High density, mono, ⌘K, tables, no animation that slows things down. |
| Street use / on the move | Large targets, strong contrast (sunlight), one action per screen, thumb reach. |
| Hours of continuous use | Calm colors, well-made dark mode, nothing blinking, adjustable density. |
| B2B (group purchase) | More trust than dazzle: proof, security, clear pricing. Boldness goes on the landing page, not in the app. |

## 4. Surface → weight of the school

| Surface | How much the school can show |
|---|---|
| Landing page | 100%. It is the shop window: hero, type and motion can go to the school's limit. |
| Corporate website / portfolio | 80–100%. |
| Slides | 80–100% on the cover and headline slides; data slides more neutral (`surface-slides`). |
| E-commerce | 50–70%. The storefront carries the school; cart and checkout follow `surface-ecommerce` to the letter. |
| Mobile app | 50–70%. Platform convention (iOS/Android) comes before style. |
| Web app / dashboard | 30–60%. Productivity first; the school lives in type, color, radius and empty states. |

## 5. Worked examples

- **Running training app for 25–40, wants "energetic + modern", mobile:** Sport **M** + Dark Tech *a*. Condensed italic numbers, dark background during the live workout, light in the history.
- **Family recipe app, "welcoming + handcrafted", mobile + website:** Handcrafted **M** + Scandinavian *a*. A serif with personality in titles, real food photos, cream paper, rounded buttons.
- **CRM for small businesses, "cool + affordable-premium", web + mobile:** Refined Minimalism **M** + Dark Tech *a* on the landing page. The house's own finish rules, if it has any, on top.
- **Workspace where people and AI agents work together, "calm + smart + trustworthy", web app:** Refined Minimalism **M** + Utilitarian *a*. Agent vs person shown by a label and the avatar shape, never by color alone. Answers appear whole or by block, no per-token fade. Motion only for state (thinking, done, failed).
- **Jewelry brand, "chic", e-commerce:** Quiet Luxury **M** + Editorial *a*. Thin display serif, photos on off-white, a single gold only on the CTA.
- **Finance app for Gen Z, "youthful + trustworthy":** Refined Minimalism **M** + Clay 3D *a* (illustration and empty states). Bento *a* can replace it on the landing page. Trust in the app, a bolder shop window.
